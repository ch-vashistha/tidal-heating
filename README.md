# tidal-heating

## Teukolsky.nb

This notebook uses the Newman–Penrose formalism for evaluating the Teukolsky equation for a specified spacetime, coordinate system, and associated null tetrad. The current implementation is for the Kerr spacetime with the Kinnersley tetrad and reproduces the standard Teukolsky master equation, including its separated radial and angular equations.

## Horizon_Tetrad_Kerr.nb

This notebook constructs a horizon-regular null tetrad for the Kerr spacetime starting from the Kinnersley tetrad in Boyer–Lindquist coordinates. A tetrad rotation is first applied, followed by a coordinate transformation to the Kerr–Schild coordinate system. The NP scalars are calculated at each stage for use in the subsequent calculations.

A tetrad rotation is first applied, followed by a coordinate transformation to the Kerr–Schild coordinate system. The NP scalars are calculated at each stage for use in the subsequent calculations.
